# Interface fonts

- Barlow Semi Condensed Regular/SemiBold, from the Google Fonts `ofl/barlowsemicondensed` source.
- Cormorant Garamond variable font, from Google Fonts `ofl/cormorantgaramond`.

Both are distributed under the SIL Open Font License. The corresponding OFL files are included
in this directory. Headings use Cormorant Garamond; compact interface text uses Barlow Semi Condensed.

Sources:
- https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
