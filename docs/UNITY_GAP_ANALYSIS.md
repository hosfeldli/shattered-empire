# Gap analysis guide

- **Type:** Navigation and historical context
- **Updated:** 2026-11-13
- **Scope:** Current Unity requirements versus implementation

Current gaps are maintained once in [Development queue](DEVELOPMENT_QUEUE.md), with evidence and
status in [Current status](UNITY_PROGRESS.md). Compare both against [Game design](GAME_DESIGN.md).

The [earlier gap analysis](archive/UNITY_GAP_ANALYSIS_BEFORE_2026-11-13.md) covered an older target.
Its civilian economy, five eras, governors, traffic and broad parity requirements do not override
the later military RTS, ring-city economy and contextual-world interaction decisions.

Use [verification](VERIFICATION.md#status-vocabulary) for completion/approval language. Do not copy
historical checkmarks into a new release checklist.
